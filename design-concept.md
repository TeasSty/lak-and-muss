# Design concept — Лак&Мусс

## Client / project

- Name: Студия красоты «Лак&Мусс» (Нижний Тагил)
- Date: 2026-11-25
- Niche: studio colorist — сложное окрашивание, AirTouch, исправление цвета, восстановление
- Concept-ID: `2026-11-25-lakmuss-dark-atelier-chapters-v1`
- Composition-archetype: `dark-atelier-chapters`
- Forbidden-for-this-niche: quiet-luxury spa black/cream/gold clone; cream `#F4F1EA`+terracotta; purple/indigo gradients; hero+3 feature cards; lead-gen `hero→services→prices→form` as composition; Syne/russet «Лисица»; Inter/Roboto; pill-glow Marco clone; stat strips in hero
- Delta-from-previous: n/a (first concept)

## Niche fingerprint

- Rituals: консультация → 4–7 ч сложный цвет/AirTouch → домашний уход L’Oréal/Davines/Matrix
- Materials: фольга, миска с пигментом, мокрые пряди, флаконы TECNI.ART / Absolut Repair, медный квадрат лого
- Places / light: кресло у зеркала; тёмный cover VK + холодный нейтральный свет на работах
- Vernacular: AirTouch, сложное окрашивание, исправление цвета, Matrix SoColor, тотал-блонд
- Sensory: запах краски, блеск меди монограммы, гладкость после ухода

## Unique thesis

1. Mood: тёмное ателье пигмента — craft колориста, не spa.
2. Type: high-contrast fashion serif caps (как ЛАК МУСС) + script monogram M; body — плотный neo-grotesk (не Inter).
3. Palette: ink black + brushed copper из лого + ash-blonde / espresso из портфолио + porcelain white.
4. Composition: `dark-atelier-chapters` — главы Цвет / Форма / Восстановление / Уход.
5. Motion: foil-shine на монограмме, soft crossfade до→после, chapter reveal (2–3).
6. Main gesture: монограмма M = hero-level brand signal на full-bleed кадре сложного цвета.

## Anti-clone checklist

- [x] Carryover: не Syne/russet Лисица, не Oswald/espresso Gretta, не filmstrip СНОВА НОВОЕ, не product-theater Sandra
- [x] Benchmark clone: у michaelalbor.com только craft (ритм/фото/hierarchy), не структура/тип/палитра
- [x] AI clusters: не purple / cream+#F4F1EA+terracotta / broadsheet / dark SaaS / hero+3 cards
- [x] Brand test: без лого остаются foil/AirTouch/главы цвета/до-после — только colorist studio

## Palette + type

- Palette:
  - `--ink: #0B0B0B` (VK cover)
  - `--ink-soft: #161412`
  - `--copper: #B8734A` (brushed monogram)
  - `--copper-bright: #D4A574`
  - `--porcelain: #F3EFE8` (не cream `#F4F1EA` как база UI — только текст/тонкие плоскости)
  - `--ash: #C8B8A4` (blonde ash accent)
  - `--espresso: #2A211C`
- Type:
  - Display: **Cormorant Garamond** — high-contrast serif, продолжает wordmark ЛАК МУСС
  - Script accent: **Great Vibes** / SVG monogram M (identity)
  - Body/UI: **Manrope** — neo-grotesk, не Inter; плотность под fashion-atelier
